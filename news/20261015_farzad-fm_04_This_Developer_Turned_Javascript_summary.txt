## Market & Competition
1. **Code-to-neural-network conversion technique:** Developer Chang's "handwired" project converts logical code structures (if/else statements, loops) into neural network components using paired "ramp" functions that mathematically replicate conditional logic, producing a network that returns the same outputs as the original code without any training process.
2. **Demonstrated use cases:** The technique was shown searching 100,000 documents entirely via a neural net, and building a minimal operating system using roughly 9,900 weights across 130 layers, running in-browser without GPU acceleration and without any training.
