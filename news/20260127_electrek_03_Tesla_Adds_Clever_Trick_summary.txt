Tesla's 2026.2.3 software update adds a new way to release a stuck charge cable: pulling and holding the rear left door handle for 3 seconds, intended to help in situations like frozen charge ports or a malfunctioning unlatch button.

## Electric Vehicles
1. **New door handle release feature:** Tesla's 2026.2.3 update lets owners stop charging and release the charge cable by pulling and holding the rear left door handle for 3 seconds, provided the vehicle is unlocked or a recognized key is nearby. The release note states this is especially useful when the cable unlatch button doesn't work or an adapter is stuck in the port; the touchscreen and app options remain available.

2. **Context on frozen charge ports:** The article notes this is a longstanding cold-weather issue for EV owners without garages, and recaps Tesla's prior fixes: a 2018 software update changing latch behavior in freezing conditions, and a more recent charge-port-specific defrosting option during preconditioning. The article's top-voted user comment disputes that the new feature actually addresses frozen or stuck cables, calling it simply an additional release method equivalent to the existing screen/app/handle options rather than a fix for ice.

## Editorial Stance
Electrek's Fred Lambert calls this a welcome, practical quality-of-life improvement — a simple physical backup that doesn't require the touchscreen or app to be responsive, useful since preconditioning isn't always a viable option depending on state of charge.
