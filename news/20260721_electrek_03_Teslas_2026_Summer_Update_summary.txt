Electrek reports on Tesla's 2026 Summer Update software release, detailing new features from Tesla's published release notes, with commentary on how each fits Tesla's product history.

## Autonomous Driving
1. **Self-driving stats added to mobile app:** Tesla's in-car tally of miles driven on its "Self-Driving" system, including streaks and monthly mileage, is now viewable and shareable from the phone app.

## Electric Vehicles
1. **Grok gains vehicle control functions:** Grok can now make phone calls, search and play music, adjust climate, open the glovebox, and answer questions about the car, building on navigation and the "Hey Grok" wake word added in the Spring Update 2026; the author notes Tesla is catching up to premium automakers, especially in China, where LLM voice assistants are already standard even in cheaper vehicles.
2. **Caraoke adds scoring:** The Caraoke feature (added in the V10 update in 2019, usable only in Park) now scores singing performance and saves high scores to the driver's Tesla profile.
3. **Navigation learns recurring routines:** Automatic Navigation now suggests and routes to regularly visited places (e.g., school drop-off, gym) beyond Home, Work, and calendar events, and prioritizes previously-taken routes over the default fastest route.
4. **Trip and customization features move to mobile app:** Arrival Energy (desired battery level at destination) can now be set from the phone app; custom vehicle wraps can be uploaded via the app instead of a USB drive, using templates from Tesla's public GitHub repository.
5. **Rear display lock:** On vehicles with rear screens (latest premium Model 3, Model Y, and Cybertruck), back-seat passengers can watch content but only front-row occupants can control playback via the rear screen app.
6. **Minor additions:** Superchargers can be found by name in destination search; Apple Music songs can be added to queue from search/artist pages; users can set a preferred zoom level for the Self-Driving visualization; the in-car browser now supports camera and microphone; new intro animations were added for Model 3 and Model Y.
