## Market & Competition
1. **Options Trading Journal Product Launch:** The IAG Journal is a newly launched desktop-based options trading journal targeting active options traders. Key features highlighted include a dashboard with monthly statistics and performance metrics, a calendar view for daily performance, an order chain view that links rolled legs of a multi-leg strategy, and a trade replay function that reconstructs a trade from entry to the close of the final leg.

2. **Broker Integration and Privacy Model:** The platform supports drag-and-drop file import from any page, as well as autosync functionality for traders using the Tastytrade or Interactive Brokers platforms. The developers emphasized a local-first privacy model: all journal data is stored on the user's own computer, with only subscription-related details held in the cloud.
