Someone just turned regular JavaScript
into a neural network. Zero training.
Same exact answers as the code. That's
the claim from developer Changlu. His
project is called handwired. Here's how
you get a brain out of code without
training it. Take one line of code. If a
number is bigger than four, answer
[music] 10. Otherwise, answer 12.
Handwired builds that out of two ramps,
a standard neural net building block.
One ramp starts at four and one starts
at five. So subtract them and you get a
clean step. Stack enough of those and
every if and every loop becomes plain
math. One demo searches 100,000
documents and the whole search is one
giant neural net. Another is a tiny
operating system. About 9900 weights,
130 layers, zero training. It runs in
your browser with no GPU. But why turn
code into a neural net if the code
already works? Because code can't learn.
This can. Chang unfreezes the weights
and trains them live right on screen.
That's the part I care about. With AI,
the way I see it, consistency is the
key. Today's models are smart, but they
drift. So, you have to build safeguards
around them. Code never drifts, but it
never learns anything new either.
Handwired is both in one brain. And
Chang's next idea goes further. Attach
one of these programs to a small
language model. So, the same network
writes Shakespeare and runs that exact
program. Creative and exact in the same
AI. That's what I want from every agent.
